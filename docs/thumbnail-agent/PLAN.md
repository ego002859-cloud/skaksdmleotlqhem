# 유튜브 썸네일 에이전트 — 기획 (v0.3)

> 이 문서는 클라우드 세션에서 기획한 내용을 로컬 Claude Code로 이어가기 위한 인계 문서다.
> 저장소 루트의 `thumbnail.html`은 기획 전에 만든 **초기 프로토타입**(AI 문구 + 캔버스 합성)이라 아래 방향과 다르다. 참고용으로만 둔다.

## 1. 서비스 정의
"영상의 주제·내용을 넣으면, 클릭하고 싶은 썸네일 **완성본 여러 장**을 만들어주고 그중 고르는 서비스"

- 여러 채널 + 다른 사람도 쓰는 서비스 (지금은 **본인이 먼저 써보는 단계**)
- 사용자 스타일 중심이 아니라 **주제·내용 중심** 제작
- 최우선 목표: 보고 싶고 클릭하고 싶게
- 현재 제작 방식: PC에서 포토샵으로 직접 제작 → 이걸 대체

## 2. 확정된 결정
| 항목 | 결정 |
|---|---|
| 입력 | 영상 요약, 주제, (있으면) 완성된 영상 첨부 |
| 인물 | 사용자가 인물 사진 제공 → AI가 주제에 맞게 **표정·제스처를 새로 생성** (같은 얼굴 유지) |
| 한글 문구 | **AI가 이미지 안에 직접 렌더링** (원스톱) |
| 결과 | 완성본 여러 장 중 고르기 |
| 서비스화·과금 | 나중에 |
| 사용 환경 | PC |

## 3. 레퍼런스 분석 (채널 캡처 5장 기준)
| | 채널 | 특징 |
|---|---|---|
| A | 실밸개발자 (메타 시니어 엔지니어) | 같은 인물을 AI로 영화 같은 장면에 넣음. 어두운 배경 + 주황/청록 조명, 인물 오른쪽 1/3, 권위 문구("메타 엔지니어가"). 최고 조회수는 유일한 흰 배경 |
| B | 김효율의 AI 개발단 | 같은 인물·같은 옷·반복 제스처(검지 들기, 손바닥), 제품 UI 배경, 하단 2줄 굵은 외곽선 문구. 공식에서 벗어난 썸네일이 조회수 최저 |
| C | AI 영상/애니메이션 채널 | 진행자 없이 주제 캐릭터·장면 + 툴 로고 아이콘 + 고정 문구 공식(1줄 흰색 "OO 미쳤다…" / 2줄 주황→노랑 "OO 종결"), 손글씨 한마디, 빨간 화살표. 최고 50만·11만 |
| D | 클로드 코드 채널 | 마스코트·로고를 3D 주인공으로 상황극, "[툴] / N분 핵심 총정리" 숫자 약속. 최고 23만 |
| E | 인테리어 채널 (AI 아님) | 손해 회피·경고형 문구("돈 낭비", "절대 하지 마세요"), 인용구, 빨간 화살표, Before/After. 최고 19만·14만 |

※ 사용자가 준 링크: @sv.developer, @lean_kim, @WonkaAI — 캡처 A~E 중 어느 것이 어느 채널인지 확인 필요

### 잘 먹히는 조건 v1
1. **2줄 문구**: 1줄 상황(흰색, 작게) / 2줄 결론·충격(강조색, 크게). 아주 굵은 고딕 + 검정 외곽선/그림자, 하단 또는 왼쪽
2. **초점 하나**: 인물 얼굴(카메라 응시 + 제스처) / 주제 캐릭터·오브젝트 / 3D 로고 중 하나
3. **후킹 패턴**: 손해 회피·경고, 종결·대체, 숫자 약속, 소수만 앎(99%는 모르는), 권위, 대결(VS), 감탄(미쳤다…)
4. **보조 요소**: 손글씨 한마디, 빨간 화살표·동그라미, 로고 아이콘, Before/After
5. **공식은 유지하되 가끔 튀게**: 채널 안 일관성 + 피드에서 튀는 색·밝기

### 스타일 프리셋 (AI가 주제에 맞게 2~3개 선택)
1. 인물 × 영화 같은 장면 (A형)
2. 인물 + 제스처 + 제품 화면 (B형)
3. 주제 캐릭터·장면 + 문구 공식 (C형)
4. 오브젝트·로고 주인공 (D형)
5. 실사 + 화살표·인용구 (E형)

제스처 목록: 가리키기, 검지 들기, 손바닥 펴기(멈춰), 팔짱, 입 가리고 놀라기, 물체 만지기
로고: AI가 그리면 틀어지므로 **원본 로고 이미지를 참고 이미지로 첨부**

## 4. 파이프라인
```
① 입력   요약·주제 (+영상) + 인물 사진 1~3장 (+로고 원본)
② 기획   클릭 포인트 분석 → 후킹 전략 → 문구 2줄 / 장면 / 제스처 / 구도 / 프리셋
③ 생성   (추천) 2단계: 문구 없는 장면 생성 → 그 이미지에 문구만 편집으로 추가
         → 장면 2개 × 문구 2개 = 4장
④ 검수   AI가 결과를 다시 보고: 한글 오타? 얼굴 동일인? 168×94에서 읽히나? 로고 정확?
         → 실패 시 해당 단계만 재생성
⑤ 선택   4장 중 고르기 → 부분 수정 요청 → 1280×720 다운로드 (2MB 이하)
```

### A형 이미지 지시문 예시
```
첨부 인물의 얼굴·헤어·체형을 그대로 유지. 검은 티셔츠.
밤의 실리콘밸리 사무실, 떠 있는 코드 홀로그램, 주황 림라이트.
인물은 오른쪽 1/3에서 홀로그램을 손가락으로 가리키며 자신감 있는 표정.
16:9 유튜브 썸네일. 왼쪽 아래에 한글 2줄을 정확히 이 글자로:
1줄 '실리콘밸리에서는' 흰색, 2줄 '이제 이렇게 코딩합니다' 중 '코딩'만 주황.
아주 굵은 고딕체, 두꺼운 검정 외곽선.
```

### C형 이미지 지시문 예시
```
화난 사무라이 클로즈업, 영화 같은 조명. 16:9 유튜브 썸네일.
왼쪽 위에 첨부한 앱 로고 아이콘 2개를 둥근 사각형으로.
하단 2줄: 1줄 '미니맥스 H3 미쳤다...' 흰색 / 2줄 'AI 애니메이션 만들기' 주황→노랑 그라데이션, 더 크게.
오른쪽 위에 노란 손글씨 '시댄스 대비 5배 싸다!'. 아주 굵은 고딕, 검정 외곽선.
```

## 5. API 구성
| 역할 | 후보 |
|---|---|
| 두뇌 (분석·기획·문구·검수) | Gemini 3 Pro/Flash (영상 직접 이해) 또는 GPT |
| 이미지 | **Nano Banana Pro** (Gemini 3 Pro Image) / **GPT Image 2** — 둘 다 비교 테스트 후 결정 |
| 빠른 시안 | Nano Banana 2 (Gemini 3.1 Flash Image) |

- OpenAI만 쓰는 경우 영상 첨부는 전처리 필요 (장면 캡처 + Whisper 음성 텍스트 변환)
- 비용 감각 (2026-08 공개 자료): Nano Banana Pro 1K/2K 약 $0.134/장 → 썸네일 1건(4장+재생성) 700~1,000원
- 키는 환경 변수로: `OPENAI_API_KEY`, `GEMINI_API_KEY` (코드·저장소에 절대 넣지 않기)
